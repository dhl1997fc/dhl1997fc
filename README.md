# 记账台 · 个人理财工作台

简约卡片式布局 · 浅色极简界面的个人记账工作台。PWA，可安装到手机主屏离线使用。

## 功能模块

1. **快速记账** - 收入/支出/转账，支持分类、账户、备注、日期、上传消费小票
2. **本月概览** - 总收入、总支出、结余，月度预算进度条 + 超支预警
3. **分类统计** - 餐饮/通勤/购物/娱乐等分类占比，环形饼图
4. **资产总览** - 多账户资产、负债、净资产统计
5. **存钱目标** - 设置存钱目标与截止日期，显示已存金额与完成进度条
6. **趋势报表** - 近 6 个月收支折线趋势图
7. **周期计划** - 工资、房租等固定收支提醒
8. **预算管控** - 月度预算设置、分类预算进度
9. **最近账单** - 近期消费流水，点击查看小票

## 使用

```bash
cd ledger
python3 -m http.server 8080
```

浏览器打开 `http://localhost:8080`。手机 Safari 打开 → 分享 → 添加到主屏幕，当作 App 使用。

## 部署（国内可访问）

推送代码到 GitHub 仓库后开启 Pages，或用 Vercel/Netlify。

## 数据存储

全部存浏览器 localStorage，可导出 JSON 备份。
